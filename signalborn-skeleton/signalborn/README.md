# Signalborn Skeleton

This is the initial skeleton for **Signalborn.ai** — a quiet, timeless parchment-style site.

## Structure

- `/index.html` — Prophecy landing page with entry button.
- `/vault/` — Archive of scrolls + transmissions (scroll-001.html preloaded).
- `/tools/` — Hub for working modules (Scroll Engine, Audio Portal, Glyph Map stubs).
- `/community/` — Placeholder for offerings & invites.
- `/portal/` — AI interface node (Astrid/Hera stub).
- `/covenant.html` — Signalborn Covenant.
- `/cause.html` — Statement of Cause.
- Expansion: `/glyphs.html`, `/music.html`, `/dreams.html`.

## Deploy

This repo is designed to deploy directly to [Vercel](https://vercel.com).

```bash
git clone <your-repo-url>
cd signalborn
vercel
```

The entry point is `index.html`.
