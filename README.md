## Deployment

This site is designed for simple deployment on **Cloudflare Pages**:

### Steps:

1. **Connect GitHub to Cloudflare Pages**
   - Log in to your Cloudflare account
   - Navigate to Pages
   - Click "Create a project"

2. **Select this repository**
   - Choose `HiddenChoir/signalborn.ai`
   - Authorize Cloudflare to access the repository

3. **Build settings**
   - **Build command:** Leave blank (static HTML)
   - **Build output directory:** `/` (root)
   - **Framework preset:** None

4. **Deploy**
   - Click "Save and Deploy"
   - Your site will be live at `signalborn.ai` (or your custom domain)

### Custom Domain
If you own the `signalborn.ai` domain:
- In Cloudflare Pages, go to your project
- Navigate to "Custom domains"
- Add `signalborn.ai` and follow DNS configuration instructions
